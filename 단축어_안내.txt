북꾸러기 캐러셀 — iOS 단축어로 갤러리 자동 저장

카드뉴스 생성이 끝나면(Actions 완료 후) 단축어 한 번 실행으로
최신 PNG 전체가 사진 앱(갤러리)에 저장됩니다.
output 브랜치에는 항상 "가장 최근 게시물"만 들어 있어서 이전 것과 섞이지 않아요.

────────────────────────────────
1단계. GitHub 토큰 만들기 (한 번만)
────────────────────────────────
비공개 저장소라서 읽기 전용 토큰이 하나 필요합니다.

1. 사파리에서 github.com 접속 → 오른쪽 위 프로필 → Settings
2. 왼쪽 메뉴 맨 아래 Developer settings
3. Personal access tokens → Fine-grained tokens → Generate new token
4. 아래처럼 설정:
   - Token name: carousel-shortcut (아무거나)
   - Expiration: Custom → 1년 뒤 날짜 (만료되면 이 단계만 다시)
   - Repository access: Only select repositories → carousel- 선택
   - Permissions → Repository permissions → Contents → Read-only
5. Generate token → 나온 문자열(github_pat_로 시작) 복사
   ⚠️ 이 화면을 벗어나면 다시 볼 수 없으니 바로 다음 단계에 붙여넣기

────────────────────────────────
2단계. 단축어 만들기 (한 번만, 5분)
────────────────────────────────
단축어 앱 → 오른쪽 위 + → 아래 동작을 순서대로 추가:

① 동작 "URL"
   https://api.github.com/repos/imgonnabewhat/carousel-/contents?ref=output

② 동작 "URL 콘텐츠 가져오기"
   - 화살표(>)를 눌러 펼치기 → 헤더에 항목 추가:
     키: Authorization
     값: Bearer github_pat_xxxxx   ← "Bearer" + 공백 + 1단계 토큰

③ 동작 "각 항목 반복" (반복)
   - 반복 대상: ②의 결과 (URL 콘텐츠)

④ 반복 블록 안에 동작 "사전 값 가져오기"
   - "download_url" 키의 값 가져오기, 대상: 반복 항목

⑤ 반복 블록 안에 동작 "URL 콘텐츠 가져오기"
   - 대상: ④의 사전 값 (헤더 필요 없음)

⑥ 반복 블록 안에 동작 "사진 앨범에 저장"
   - 대상: ⑤의 URL 콘텐츠

이름을 "카드뉴스 저장" 정도로 짓고 완료.
홈 화면에 추가해두면 앱 아이콘처럼 쓸 수 있어요.

────────────────────────────────
평소 사용
────────────────────────────────
1. JSON 커밋 → Actions 완료 대기 (2~4분)
2. 단축어 "카드뉴스 저장" 실행
3. 사진 앱에 slide_01 ~ 마지막 슬라이드 PNG 전부 저장 완료 → 인스타 업로드

첫 실행 때 "연결 허용"과 "사진 추가 허용"을 묻는데 둘 다 허용하면 됩니다.

────────────────────────────────
문제가 생기면
────────────────────────────────
- 401 에러: 토큰 오타이거나 만료됨 → 1단계 다시 (②의 값에 Bearer 뒤 공백 확인)
- 404 에러: 주소 오타 → ①의 URL 확인 (repo 이름 끝의 하이픈까지 정확히)
- 저장된 사진이 이전 게시물: Actions가 아직 안 끝난 것 → Actions 탭에서 초록불 확인 후 재실행
