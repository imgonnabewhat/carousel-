=== GitHub 전체 교체 안내 ===

[교체할 파일] — 저장소에서 같은 이름 파일을 이 폴더의 것으로 교체
  builders.js / free_page.js / fetch_images.js / generate.js / preview.js / template.html
  .github/workflows/generate.yml
  generated_data.json   ★ 주의: 현재 저장소의 '위로 에세이' JSON이
                          '과일 에세이'(최신 형식, 검증 완료)로 바뀝니다.
                          위로 에세이를 살리고 싶으면 클로드에게
                          "위로 에세이 최신 형식으로 다시 만들어줘"라고 요청.
  (README 3개는 선택)

[교체 방법 — GitHub 앱/웹]
  방법 A(웹, 노트북 권장): 저장소 → Add file → Upload files →
    이 폴더의 파일 전부 드래그 → Commit. 같은 이름이면 자동으로 교체됨.
    .github 폴더는 드래그가 안 되면: 저장소에서 .github/workflows/generate.yml
    열기 → 연필 → 내용 전체 교체 → Commit.
  방법 B(파일별): 각 파일 열기 → 연필(Edit) → 전체 삭제 → 새 내용 붙여넣기 → Commit.

[건드리지 말 것]
  package.json / package-lock.json  → 저장소에 있는 그대로 둘 것 (교체·삭제 금지)
  Secrets(API 키)                    → 그대로 유지

[교체 후 테스트]
  1. generated_data.json 커밋이 끝나면 Actions가 자동 실행 (2~4분)
  2. 초록 완료 → Artifacts → carousel-png 다운로드
  3. 확인 포인트:
     - 2번째 장이 '타원 사진 인트로'(복숭아)로 나오면 코드 최신화 성공
     - 책 표지 4권이 들어가 있으면 네이버 키 정상
     - 표지가 여전히 회색 박스라면 → Actions 로그의 '책 표지 수집' 부분
       스크린샷을 클로드에게 (네이버 키 문제로 확정됨)
